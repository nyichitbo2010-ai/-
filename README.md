# NEON RECAP Mini App — UI v4

A mobile-first Telegram Mini App frontend prototype.

## Included
- Brighter cyberpunk terminal with `$` prompts and character-by-character syntax-colored typing.
- Movie Recap modes: Normal Recap and Full Movie.
- Audio Book mode accepts a YouTube link in the project form (no transcript file field).
- Ref voice configuration cards for `ref.wav`, `ref.txt`, and `link.txt` with English-only UI labels.

## Run locally
Open `index.html`, or run `python -m http.server 8000` in this directory and open `http://localhost:8000`.

This is frontend-only. File selection and form actions are demos until a backend is connected. Do not put API keys in frontend code.
